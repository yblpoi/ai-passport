# 像素纪念日摆件 —— 数着在一起的日子

本分支（`feature/love-anniversary-pixel`）把 FoloToy AI Passport 做成一个成品应用：
一块桌面摆件，正面数着"在一起多少天"，也数着接下来要过的每一个日子。不要账号、
不依赖云服务、也不需要配套 App —— 一切都在设备上运行，配置页面由设备自己提供。

上游的平台说明仍在 [docs/README.zh_CN.md](docs/README.zh_CN.md)，本文只介绍本分支的固件。

设备开机直接进入应用，没有测试菜单、也没有中间页：整个界面就是一个主屏、一圈事件页、
一个设置页和一个本机状态页。

## 设备上有什么

| 屏幕 | 内容 |
| --- | --- |
| 主屏 | 两个人（图标或照片）、"在一起"标签、大数字、起始日，右上角是电量 |
| 事件卡 | 一条事件占一屏：图标、名称、大数字倒计时，以及折算后的目标日 |
| 列表页 | 一屏 4 条，按分类分组，每行显示自己的天数。列表页没有条目光标，上/下 只翻页 |
| 设置页 | 后台热点开关、后台地址、热点密码、网络、时间、自动熄屏档位、蓝牙串口开关、本机状态 |
| 本机状态页 | 电量百分比与电压、网络、时间及来源、蓝牙状态、剩余内存、运行时长、各任务栈余 |
| 确认页 | 一个问题，短按确定 = 允许，长按确定 = 拒绝；蓝牙链路上的危险命令会弹它 |

主屏与各页构成一个闭合的圈：主屏 → 单页事件卡 → 列表页 → 主屏。页码是这一整圈里的
第几页，所以单页卡与列表页共用一套编号；上/下 越过两端都回主屏。

## 怎么操作

机身三个键：上、下、确定。一次物理按键会被按键驱动拆成好几个事件，只有判定事件
（短按、连按两次、长按）才算"用户要做的事"。

| 手势 | 位置 | 结果 |
| --- | --- | --- |
| 上 / 下（短按） | 主屏 | 进轮播：下键从第 0 页进，上键从最后一页进 |
| 上 / 下（短按） | 轮播的任意一页 | 上一页 / 下一页 |
| 上（连按两次） | 轮播的任意一页 | 一步回主屏 |
| 确定（短按） | 轮播的任意一页 | 不做事：列表页没有光标，日期一律在后台网页改 |
| 确定（短按） | 设置页 / 状态页 | 执行选中的动作 |
| 确定（长按） | 主屏、轮播、任意一页 | 打开设置页 |
| 确定（长按） | 设置页 | 回主屏 |
| 任意判定事件 | 熄屏时 | 只亮屏，这次按键不当作动作下发 |

空闲行为是一套实测出来的规则：

- **自动熄屏**（15 秒 / 30 秒 / 1 分钟 / 3 分钟 / 常亮，出厂默认 30 秒）：这么久没有按键
  就关背光。关背光前先回到主屏，所以熄屏后再看，永远从同一个地方开始。
- **空闲深睡**：最后一次按键满 5 分钟、屏幕已熄、后台网页也已空闲、且没有蓝牙台连着时
  睡下去。按键唤醒，而唤醒是一次重启 —— 设备会重新联网、重新对时。档位设成"常亮"或
  打开调试模式都会关掉这一步。
- 细节（包括"为什么连着的蓝牙客户端会让它不睡"）见[电源与空闲](docs/development/engineering/power-and-idle.zh_CN.md)。

## 倒计时怎么算

每条事件保存名称、图标、类型、日期、可选分类和展示方式。三种类型的行为不同：

| 类型 | 行为 |
| --- | --- |
| 每年重复 | 折算到下一次发生日：今天当天算今天，今年已过则取明年；2 月 29 日在平年折算到 2 月 28 日 |
| 仅一次 | 按完整日期算，过期后改显示已经过去多少天 |
| 农历 | 存农历月与日（日 = 0 表示该月最后一天，用于除夕），折算到下一次对应的公历日期 |

设备没有实时时钟。时间来自三条路：联网后自动 SNTP、后台网页的"用手机当前时间对时"、
或两种控制台上的 `time` 命令。第一次对上时之前，倒计时显示占位符而不是数字，状态页会
写明当前时间来自哪里。日期按 UTC+8 计算。

内置农历表覆盖 2018–2050 年；超出这个范围时应用会明说"算不出来"，而不是给一个错的日期。

## 后台网页

用手机打开设备自己的网页。页面与设备同素材、同配色，预览里的天数也按同一套规则即时算。

| 项 | 值 |
| --- | --- |
| 热点名 | `LoveCount-XXXX`，XXXX 由设备 MAC 推出 |
| 热点密码 | 每台设备随机生成一次并存在 NVS；设备设置页会显示，热点开着时后台页也显示 |
| 热点上的地址 | `http://192.168.4.1` |
| 局域网地址 | 设备设置页上显示（由路由器 DHCP 分配，随时可能变） |

设备没有保存过任何网络时会自动开热点。热点在最后一次使用满 5 分钟后自动关闭，也可以在
页面上手动关；**手动关过就一直记着**，设备不会再自己把它开回来 —— 想找回来就在页面上
"清除全部凭据"，它会重新开热点。

页面上能做的事：

- **预览**：按当前值渲染主屏与事件卡。
- **在一起**：起始日、两个人名字，以及各自的头像 —— 18 个内置像素图标，或 4 个上传的照片。
- **显示**：自动熄屏档位，以及每条事件的展示方式（列表或单页）。
- **倒计时事件**：增删、编辑、上下移、收起；选图标、类型（每年重复 / 仅一次 / 农历）、
  日期、分类和展示方式。上限 24 条。
- **时间**：看设备时间与来源，用手机当前时间给它对时。
- **网络与热点**：扫描、保存、删除网络（最多记 5 个，开机与断线后会连信号最强的那个），
  以及手动开/关热点。
- **蓝牙串口**：开关。
- **保存**：把整份配置写回设备。

上传的照片不会离开手机：浏览器把它裁成正方形、缩到 240×240，再压成设备保存的
40×40、16 色、4bpp 图像。预设负责"更贴近原图 / 更干净 / 大片平涂"，另外五个旋钮暴露
同一组参数。算法与它的契约见[头像像素化](docs/development/engineering/avatar-pixelation.zh_CN.md)。

## 串口控制台

USB 串口（USB Serial/JTAG）一直都在；蓝牙串口出厂关闭，打开后也广播成 `LoveCount-XXXX`，
用的是标准 NUS 服务，常见的 BLE 串口 App 不用手配 UUID 就能连。蓝牙空闲 5 分钟自动关闭，
有人连着时不自动关。

| 命令 | 用途 |
| --- | --- |
| `help` | 列出所有命令 |
| `status` | 时间、网络、蓝牙、内存、各任务栈余，以及当前停在哪一屏 |
| `wifi` | 配网：`wifi`、`wifi list`、`wifi <名称> <密码>`、`wifi del <序号\|名称>`、`wifi clear` |
| `ap` | 后台热点：`ap`、`ap on`、`ap off` |
| `ble` | 蓝牙串口：`ble`、`ble on`、`ble off` |
| `time` | 看时间，或 `time <Unix 秒>` 写时间 |
| `log` | 日志级别 |
| `shot` | 把当前屏幕以 RGB565 经 USB 串口发出，由 `tools/screenshot.py` 存成 PNG |
| `debug` | 调试模式：不熄屏、不深睡，直到关掉（仅 USB） |
| `sleep` | 调试睡眠：`sleep light`、`sleep deep [秒]`（仅 USB） |
| `key` | 调试注入一整套按键手势：`key up`、`key long`、`key dbl up`（仅 USB） |

从蓝牙进来的危险命令（改 Wi-Fi、关热点、写时间）会让设备在屏幕上要求确认 —— 短按确定
允许，长按确定拒绝。USB 侧不要求确认：插上线本身就是物理接触。

## 出厂默认与隐私

下面的值只对"没有存过配置"的设备生效，也就是新机或恢复出厂之后的机器。已经存过配置的
设备保持主人自己选的那套。

| 项 | 出厂值 |
| --- | --- |
| 起始日 | 2000-01-01 |
| 两个人 | 两个占位昵称：「咕咕」与「嘎嘎」，小鸟与猫咪图标 |
| 事件 | 元旦、情人节、生日占位、国庆节、圣诞节，以及农历的春节、中秋、七夕 —— 都在列表屏 |
| 生日占位 | 名称「咕咕嘎嘎」、日期 **2000-01-01**、每年重复、蛋糕图标 |
| 自动熄屏 | 30 秒 |
| 蓝牙串口 | 关 |

出厂数据刻意不放任何真人信息：两个名字都是占位昵称，起始日与生日用的是同一个一眼假的
日期（2000-01-01）—— 第一次打开后台页就把它们改成自己的，或者删掉生日那一行。仓库里
不含任何 Wi-Fi 凭据、设备二维码秘密或上传的照片，那些只存在于设备自己的 NVS 分区里。

## 构建、烧录与验证

用 ESP-IDF 5.5.3 构建。唯一认可的判据是仓库的门禁：

```bash
source <path-to-esp-idf-v5.5.3>/export.sh

./tools/validate.sh --static     # 仓库检查 + host tests
./tools/validate.sh --firmware   # 隔离目录里的 ESP-IDF 构建 + 合并镜像校验
./tools/validate.sh              # 完整门禁
```

空白设备或有意做一次完整刷新时，烧校验过的合并镜像，从 `0x0` 写入：

```bash
python -m esptool --chip esp32c3 -p <port> -b 460800 \
    write-flash 0x0 build/FoloToy-AI-Passport-full.bin

# 增量开发：只烧应用，设备上已有的配置保持不变
idf.py -p <port> flash monitor
```

合并镜像可能重置已保存的设置；需要保住它们时走分段烧录的那条路。分区表仍是上游的最小
默认布局 —— NVS、PHY 数据，以及一个占满其余 8 MB Flash 的 factory 应用；见
[固件布局](docs/development/engineering/firmware-layout.zh_CN.md)与
[构建与验证](docs/development/engineering/build-and-test.zh_CN.md)。

## 已知限制

- 倒计时依赖对过时的时间。整机断电重启、且还没重新联网时，与日期相关的界面会回落到上次
  存下的快照，或显示占位符。
- 从深睡唤醒等于一次重启：屏幕回来了，但 Wi-Fi、HTTP、蓝牙都要重新起来。
- 农历表只到 2050 年；超出范围时应用会明说这一点，不猜。
- 日期按 UTC+8 计算，目前没有时区设置。
